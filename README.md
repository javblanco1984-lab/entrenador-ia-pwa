# Entrenador IA PWA

Prueba mínima, personal y de solo lectura para validar este recorrido:

`GitHub Pages → Google OAuth → Apps Script API → Google Sheets`

## Garantías de esta fase

- No contiene datos de entrenamiento.
- No guarda respuestas de Google Sheets localmente.
- No incluye ninguna función de escritura.
- No requiere servicios de pago ni facturación.

Los valores públicos de OAuth y del despliegue se completarán en `config.js` una
vez creados. El identificador de la hoja y la cuenta autorizada se guardarán como
propiedades privadas de Apps Script y nunca se publicarán en GitHub.
